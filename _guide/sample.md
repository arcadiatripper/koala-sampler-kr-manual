## SAMPLE에서 하는 일

SAMPLE 화면은 소리 재료를 준비하는 작업대입니다. 처음에는 아래 세 가지 기능만 익혀도 충분합니다.

- 마이크로 직접 녹음하기
- 기기에 있는 오디오 파일 가져오기
- 시작점과 끝점을 움직여 필요한 부분만 남기기

> **앱에 보이는 영어는 그대로 적습니다.**
>
> 예를 들어 버튼에 `RESAMPLE FROM APP`이라고 적혀 있다면 번역된 이름으로 바꾸지 않습니다. 대신 바로 아래에서 쉬운 한국어로 뜻을 설명합니다.
{: .guide-note .guide-note--start }

<h2 id="source">1. 소리를 어디에서 가져올지 고르기</h2>

이 가이드에서는 소리를 가져오는 입력 방법을 **소스(source)**라고 부릅니다. 화면 위쪽의 입력 메뉴를 누르면 방법을 바꿀 수 있습니다.

### 마이크로 녹음하기

{% include v2/image.html src="menu-input-menu-record-from-mic.png" alt="SAMPLE 입력 메뉴에서 마이크 녹음이 선택된 모습" caption="기본 상태에서는 기기의 마이크가 입력으로 선택됩니다." compact=true %}

`RECORD FROM MIC`이 선택된 상태에서 빈 패드를 길게 누르세요. 누르는 동안 녹음되고, 손을 떼면 멈춥니다.

> **이어폰을 사용해보세요.**
>
> 스피커에서 나오는 소리가 마이크로 다시 들어가는 것을 줄일 수 있습니다.
{: .guide-note .guide-note--tip }

### 오디오 파일 가져오기

{% include v2/image.html src="sample-input-menu-import-file.png" alt="SAMPLE 입력 메뉴에서 IMPORT FILE을 고르는 모습" caption="IMPORT FILE을 선택하면 빈 패드를 눌렀을 때 파일 선택 화면이 열립니다." compact=true %}

1. 입력 메뉴를 열고 `IMPORT FILE`을 선택하세요.
2. 빈 패드를 누르세요.
3. 사용할 오디오 파일을 고르세요.
{: .task-steps }

> **화면 확인**
>
> 선택한 패드에 파형이 나타나고, 패드를 탭했을 때 파일의 소리가 들리면 성공입니다.
{: .success-check }

<h2 id="resample">2. Koala 안의 소리를 다시 녹음하기</h2>

{% include v2/image.html src="sample-input-menu-resample.png" alt="입력 메뉴에서 RESAMPLE FROM APP을 선택한 모습" caption="RESAMPLE FROM APP은 Koala 안에서 재생되는 결과를 새 패드에 녹음합니다." compact=true %}

`RESAMPLE FROM APP`은 Koala 안에서 들리는 소리를 새 샘플로 녹음하는 기능입니다.

예를 들어 여러 패드를 함께 연주하거나 `PERFORM` 이펙트를 적용한 결과를 패드 하나에 담을 수 있습니다.

1. 입력 메뉴에서 `RESAMPLE FROM APP`을 선택하세요.
2. 녹음할 빈 패드를 한 번 누르세요.
3. 다른 패드를 연주하거나 시퀀스를 재생하세요.
4. 녹음 중인 패드를 다시 눌러 멈추세요.
{: .task-steps }

> **RESAMPLE을 한 문장으로**
>
> “지금 Koala에서 들리는 결과를 새 소리로 다시 녹음하기”입니다.
{: .guide-note .guide-note--term }

<h2 id="edit">3. 필요한 구간만 남기기</h2>

{% include v2/image.html src="sample-editor-selection.png" alt="샘플 편집기에서 시작점과 끝점이 선택된 파형" caption="파형 양쪽의 손잡이를 움직여 재생할 구간을 정합니다." %}

1. 소리가 들어 있는 패드를 선택하세요.
2. `EDIT`를 누르세요.
3. 파형 왼쪽 손잡이를 움직여 시작점을 정하세요.
4. 오른쪽 손잡이를 움직여 끝점을 정하세요.
5. 패드를 눌러 선택한 구간을 들어보세요.
{: .task-steps }

> **화면 확인**
>
> 패드를 누를 때 선택한 시작점에서 소리가 시작하고 끝점에서 멈추면 성공입니다.
{: .success-check }

## 지금은 몰라도 되는 기능

다음 기능은 필요할 때 천천히 배워도 됩니다.

- `AUTO-CHOP`: 긴 소리를 여러 조각으로 나누기
- `STRETCH`: 소리 길이를 곡의 BPM에 맞추기
- `SPLIT STEMS`: 완성된 곡을 드럼, 보컬, 베이스 등으로 나누기
- `MIX / EQ`: 소리의 저음, 중음, 고음 다듬기

일부 기능은 `SAMURAI` 또는 `MIXER` 추가 구매가 필요할 수 있습니다. 앱의 구매 화면과 공식 설명을 함께 확인하세요.
