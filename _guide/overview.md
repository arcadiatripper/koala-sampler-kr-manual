## 먼저 기억할 흐름

1. `SAMPLE`에서 사용할 소리를 준비합니다.
2. `SEQUENCE`에서 패드를 누른 순서와 타이밍을 기록합니다.
3. `PERFORM`에서 시퀀스를 바꾸고 이펙트를 연주합니다.
4. `MENU`에서 곡을 저장하거나 파일로 내보냅니다.
{: .lesson-outline }

> **처음부터 모든 기능을 외울 필요는 없습니다.**
>
> 화면을 이동할 때 “지금 재료를 준비하는 중인지, 리듬을 기록하는 중인지”만 구분해도 길을 잃지 않습니다.
