> **시작하기 전에**
>
> Koala Sampler를 열고 아래쪽의 `SAMPLE`이 선택되어 있는지 확인하세요. 처음에는 마이크 녹음만 사용합니다.
{: .guide-note .guide-note--start }

## 완성할 것

이번 실습에서는 네 가지 동작만 합니다.

1. 빈 패드에 손뼉 소리를 녹음합니다.
2. `SEQUENCE`에서 두 마디 리듬을 기록합니다.
3. `PERFORM`에서 이펙트를 만져봅니다.
4. 작업을 저장합니다.
{: .lesson-outline }

## 1. 빈 패드에 소리 녹음하기

{% include v2/image.html src="sample-record-to-pad.png" alt="SAMPLE 화면에서 빈 패드를 길게 눌러 녹음하는 모습" caption="빈 패드를 길게 누르는 동안 마이크 소리가 녹음됩니다." compact=true %}

1. 화면에서 아무 빈 패드나 길게 누르세요.
2. 손가락을 누른 채 손뼉을 한 번 치세요.
3. 패드에서 손가락을 떼세요.
{: .task-steps }

> **화면 확인**
>
> 방금 누른 패드에 작은 파형이 보이고, 패드를 탭했을 때 손뼉 소리가 들리면 성공입니다.
{: .success-check }

> **PAD가 무슨 뜻인가요?**
>
> `PAD`는 소리를 담아두고 눌러서 재생하는 네모난 칸입니다. 이 가이드에서는 앱에서 찾기 쉽도록 **패드**라고 씁니다.
{: .guide-note .guide-note--term }

## 2. 두 마디 리듬 녹음하기

{% include v2/image.html src="sequence-rec-armed.png" alt="SEQUENCE 화면에서 녹음 버튼이 활성화된 모습" caption="빨간 녹음 버튼을 누른 뒤 패드를 연주합니다." %}

1. 아래쪽에서 `SEQUENCE`를 누르세요.
2. 빈 시퀀스 칸을 하나 선택하세요.
3. 마디 수를 표시하는 버튼을 눌러 `2 BARS`를 선택하세요.
4. 빨간 녹음 버튼을 누르세요.
5. 박자에 맞춰 방금 녹음한 패드를 몇 번 눌러보세요.
6. 녹음 버튼을 다시 눌러 녹음을 끝내세요.
{: .task-steps }

> **화면 확인**
>
> 재생할 때 패드를 누르지 않아도 손뼉 소리가 반복되면 성공입니다.
{: .success-check }

> **처음에는 박자가 조금 어긋나도 괜찮습니다.**
>
> 연주 타이밍을 반듯하게 맞추는 `QUANTIZE`는 나중에 배워도 됩니다.
{: .guide-note .guide-note--tip }

## 3. PERFORM에서 직접 연주하기

{% include v2/image.html src="perform-live-fx.png" alt="PERFORM 화면에 16개의 실시간 이펙트가 표시된 모습" caption="재생 중 원하는 이펙트 영역을 누르거나 밀어서 소리를 바꿉니다." %}

1. 아래쪽에서 `PERFORM`을 누르세요.
2. 재생 버튼을 누르세요.
3. 화면의 `FILTER`나 `STUTTER` 영역을 손가락으로 눌러보세요.
4. 손가락을 떼면 원래 소리로 돌아옵니다.
{: .task-steps }

> **화면 확인**
>
> 재생은 계속되면서 손가락을 댄 동안만 소리가 달라지면 성공입니다.
{: .success-check }

## 4. 작업 저장하기

{% include v2/image.html src="menu-save-as.png" alt="곡 이름을 입력하고 저장하는 창" caption="처음 저장할 때는 알아보기 쉬운 이름을 붙여주세요." %}

1. 메뉴 버튼을 누르세요.
2. `SAVE AS`를 선택하세요.
3. 곡 이름을 입력하고 `SAVE`를 누르세요.
{: .task-steps }

## 첫 비트를 완성했습니다

이제 Koala의 기본 흐름을 한 번 경험했습니다.

`SAMPLE`에서 소리를 준비하고 → `SEQUENCE`에서 순서를 기록하고 → `PERFORM`에서 연주합니다.

다음에는 SAMPLE 화면에서 마이크 외에 파일을 가져오고, 소리의 시작점과 끝점을 다듬는 방법을 알아보세요.
