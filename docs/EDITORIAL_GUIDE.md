# Koala Sampler 한국어 가이드 편집 규칙

## 독자

- Koala Sampler를 처음 사용하는 한국어 사용자
- 음악 제작 경험이 많지 않은 중학생 이상 독자
- 앱의 영어 UI를 보면서 한국어 설명을 함께 읽는 사용자

## 언어 원칙

1. 앱에 실제로 보이는 버튼, 탭, 메뉴는 영어 원문 그대로 쓴다.
2. UI 라벨은 대문자와 인라인 코드로 구분한다. 예: `RESAMPLE FROM APP`.
3. 동작 설명은 자연스러운 한국어로 쓴다.
4. 음악·기술 용어는 처음 한 번만 영어를 병기하고 이후 한국어 표기를 사용한다.
5. `입력 source`, `sequence 녹음`처럼 문장 안에서 일반 명사를 임의로 영어로 바꾸지 않는다.
6. 한 문장에는 한 가지 동작이나 개념만 담는다.

## 제목 원칙

- 대제목: `SAMPLE — 소리 넣고 다듬기`
- 기능 제목: `Monitoring Input — 입력 소리 듣기`
- `한국어 (English)`를 반복하는 제목은 사용하지 않는다.
- 영어 제목만으로 뜻을 알기 어려우면 대시 뒤에 짧은 목적 설명을 붙인다.

## 학습 단계

1. 무엇을 할 것인지 먼저 설명한다.
2. 한 단계에 한 동작만 적는다.
3. 실제 UI 라벨을 정확히 표시한다.
4. 단계 끝에는 화면이나 소리로 확인할 수 있는 성공 조건을 제공한다.
5. 선택적인 고급 기능은 기본 흐름에서 분리한다.

## 호출상자

- 시작하기: 진행 전에 꼭 필요한 조건
- 화면 확인: 단계가 성공했는지 확인하는 방법
- 처음 보는 말: 현재 작업에 반드시 필요한 용어
- 팁: 선택 사항이지만 결과를 분명히 개선하는 정보
- 주의: 데이터 손실, 비용, 플랫폼 제한 또는 실패 위험

같은 설명은 한 번만 작성한다. 다른 페이지에서는 대표 설명으로 연결한다.

## 최신성

- 기능 페이지에는 공식 원문 URL과 마지막 확인 날짜를 기록한다.
- 플랫폼과 유료 기능 여부를 추측하지 않는다.
- 공식 매뉴얼, 공식 사이트, 공식 릴리스 노트가 충돌하면 날짜가 더 최근인 자료를 확인하고 충돌을 기록한다.

## 면책 안내

- 이 사이트가 개인이 만든 비공식 가이드라는 점을 분명히 밝힌다.
- 앱과 가이드가 다르면 현재 앱, 스토어 설명과 공식 자료를 우선하도록 안내한다.
- 제품 권리, 사용자 오디오 권리, 인앱 구매와 데이터 백업 책임을 서로 구분해서 설명한다.
- 한국어와 영어 면책문은 항목별로 함께 제공하고, 제품 정보는 언어와 관계없이 공식 자료가 우선한다고 적는다.

## 유료 기능 표기

- 기능명 바로 뒤에 `[SAMURAI]` 또는 `[MIXER]`를 적어 빌드 시 유료 기능 배지로 바꾼다.
- 직접 작성한 v2 가이드 본문에서는 `v2/addon-badge.html` include를 사용한다.
- `SAMURAI`는 타임스트레치, 피아노 롤, AUTO-CHOP, 패드별 3밴드 EQ, QUOKKA SYNTH, MIDI OUT에 표시한다.
- `MIXER`는 믹서 화면, 패드의 버스 라우팅, 믹서 채널 조절, 믹서 이펙트와 외부 플러그인 호스팅에 표시한다.
- 기본 키보드 모드, 일반 시퀀스 그리드, 패드 MUTE/SOLO, PERFORM FX, 배경 이펙트와 AUv3 멀티 버스 출력에는 애드온 배지를 붙이지 않는다.
- 패드별 3밴드 EQ는 `SAMURAI`, 믹서 채널에 넣는 EQ 이펙트는 `MIXER`임을 문맥에서 구분한다.
