# Koala Sampler 한국어 가이드 디자인 시스템

## 방향

Koala Sampler의 어두운 화면과 핑크 포인트는 유지한다. 강한 색과 배경 질감은 정보 강조에만 제한하고, 긴 글을 읽는 영역은 단색에 가깝게 만든다.

## 색상

- Canvas: `#1B1C20`
- Surface: `#24262B`
- Raised surface: `#2B2E34`
- Text: `#F1F2F4`
- Muted text: `#B8BCC6`
- Soft Koala pink: `#E66A80`
- Original Koala pink: `#FE2E5A` — 현재 위치, 작은 상태 표시, 브랜드 장식에만 사용
- Success: `#8FD3B2`
- Warm note: `#E7C47A`

## 글꼴

- 한영 혼합 제목과 본문: Pretendard 우선의 한국어 시스템 산세리프
- 영문 브랜드 라벨: Dosis
- 본문 굵기: 400–450
- 제목 굵기: 650–700
- 본문 줄간격: 1.7
- 읽기 영역 최대 폭: 약 760px

## 반응형

- 콘텐츠 URL은 기기와 관계없이 하나만 사용한다.
- 화면 폭에 따라 모바일 또는 태블릿 스크린샷을 자동 선택한다.
- 모바일 장 제목은 32–36px 범위로 제한한다.
- 데스크톱에는 왼쪽 목차, 모바일에는 접근 가능한 메뉴 버튼을 제공한다.

## 이미지

- 실제 Koala 앱 스크린샷을 사용한다.
- 장식 목적의 새 로고나 캐릭터를 만들지 않는다.
- 이미지에는 한국어 대체 설명과 짧은 캡션을 제공한다.
- 지연 로딩과 반응형 이미지 선택을 기본으로 사용한다.
