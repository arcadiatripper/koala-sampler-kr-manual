# Koala Sampler 한국어 가이드 디자인 시스템

## 방향

Koala Sampler의 어두운 화면과 핑크 포인트는 유지한다. 강한 색과 배경 질감은 정보 강조에만 제한하고, 긴 글을 읽는 영역은 단색에 가깝게 만든다.

## 색상

- Canvas: `#1B1C20`
- Surface: `#24262B`
- Raised surface: `#2B2E34`
- Text: `#F1F2F4`
- Muted text: `#B8BCC6`
- Soft Koala pink: `#E66A80`
- Original Koala pink: `#FE2E5A` — 현재 위치, 작은 상태 표시, 브랜드 장식에만 사용
- Success: `#8FD3B2`
- Warm note: `#E7C47A`
- Mixer add-on: `#8BBCFF`

## 유료 기능 배지

- `SAMURAI`는 노란색, `MIXER`는 파란색 알약 모양 배지로 구분한다.
- 색만으로 의미를 전달하지 않고 배지 안에 애드온 이름을 항상 표시한다.
- 기능명이나 기능 제목 바로 뒤에 놓고, 배지를 누르면 유료 확장 기능 설명으로 이동한다.
- 긴 기능 목록은 중간 링크로 바로 들어온 독자도 조건을 알 수 있도록 각 기능 제목에 배지를 반복한다.

## 글꼴

- 한영 혼합 제목과 본문: Pretendard 우선의 한국어 시스템 산세리프
- 영문 브랜드 라벨: Dosis
- 본문 굵기: 400–450
- 제목 굵기: 650–700
- 본문 줄간격: 1.7
- 읽기 영역 최대 폭: 약 760px

## 반응형

- 콘텐츠 URL은 기기와 관계없이 하나만 사용한다.
- 화면 폭에 따라 모바일 또는 태블릿 스크린샷을 자동 선택한다.
- 모바일 장 제목은 32–36px 범위로 제한한다.
- 데스크톱에는 왼쪽 목차, 모바일에는 접근 가능한 메뉴 버튼을 제공한다.

## 탐색과 검색

- 상단 탐색은 `QUICK GUIDE`, `MANUAL`, `FAQ`, 검색 아이콘, `OFFICIAL MANUAL`만 유지한다.
- 별도의 전체 기능 허브를 만들지 않고 화면별 가이드와 왼쪽 목차를 사용한다.
- 검색은 페이지를 이동하지 않는 오버레이로 열고 입력과 동시에 결과를 표시한다.
- 검색 아이콘에는 접근 가능한 이름을 제공하고, `Esc`와 닫기 버튼으로 검색창을 닫을 수 있어야 한다.
- `NOTICE — 안내와 면책`은 왼쪽 목차와 푸터에서 항상 찾을 수 있게 한다.

## 이미지

- 실제 Koala 앱 스크린샷을 사용한다.
- 장식 목적의 새 로고나 캐릭터를 만들지 않는다.
- 이미지에는 한국어 대체 설명과 짧은 캡션을 제공한다.
- 지연 로딩과 반응형 이미지 선택을 기본으로 사용한다.
