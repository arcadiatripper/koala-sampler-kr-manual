## 7.7. 내보내기 옵션 (Export Options)

* CURRENT SAMPLE: 현재 선택한 패드를 WAV 파일로 내보냅니다.
* ALL SAMPLES: 곡의 모든 샘플을 하나의 ZIP 파일로 내보냅니다.
* CURRENT SEQUENCE: 현재 시퀀스를 내보냅니다. 스템을 선택하면 패드마다 별도의 WAV 파일이 만들어지고, 믹스를 선택하면 하나의 WAV 파일이 만들어집니다.
* ALL SEQUENCES: 모든 시퀀스를 내보냅니다. 스템은 모든 패드를 각각 파일로 만들고, 믹스는 시퀀스마다 하나의 WAV 파일을 만듭니다.
* SHARE KOALA SONG: .koala 곡 파일을 만들어 다른 기기나 사람과 공유합니다.
* ABLETON DRUM RACK: 모든 패드가 담긴 Ableton Drum Rack .adg 파일을 만듭니다.
* ABLETON LIVE SET: Ableton Live에서 이어서 작업할 수 있는 루프나 개별 시퀀스 스템을 만듭니다.
* GET ABLETON LIVE LITE: 이메일 주소를 입력해 무료 Ableton Live Lite 버전을 받을 수 있는 확인 창을 엽니다.
