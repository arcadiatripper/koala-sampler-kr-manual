Koala는 독립 실행 앱으로 사용할 수 있고, iOS에서는 AUM, GarageBand, Logic Pro 같은 음악 앱 안에 AUv3 악기(AUv3 instrument) 또는 AUv3 이펙트(AUv3 effect)로 불러와 사용할 수도 있습니다. AUv3 기능은 안드로이드에서 제공되지 않습니다.

이미지: AUM 안에서 악기, 이펙트, 악기에서 이펙트로 연결된 형태로 사용되는 Koala 화면입니다.

멀티 버스 이펙트(multi-bus effect)로 사용할 때 Koala는 앱의 메인 입력(main input)으로 오디오를 받습니다. 각 패드는 DAW 앱에서 따로 처리할 수 있도록 8개의 다른 출력 채널(output channel)에 배정할 수 있습니다. 이 기능 역시 iOS에서만 사용할 수 있습니다.

> 📘 용어 설명:
> **AUv3** — iPhone이나 iPad에서 음악 앱 안에 다른 음악 앱이나 플러그인을 불러와 사용할 수 있게 해주는 형식입니다. 쉽게 말하면 iOS/iPadOS용 플러그인 규격입니다.  
> **독립 실행 앱(standalone app)** — 다른 앱 안에서 불러오는 것이 아니라, Koala를 그냥 하나의 앱으로 실행해서 쓰는 방식입니다.  
> **AUv3 악기(AUv3 instrument)** — Koala를 다른 음악 앱 안에서 악기처럼 불러오는 방식입니다. 예를 들어 AUM이나 GarageBand 안에서 Koala를 하나의 악기 트랙처럼 사용할 수 있습니다.  
> **AUv3 이펙트(AUv3 effect)** — Koala를 이펙트처럼 불러오는 방식입니다. 다른 앱에서 들어오는 소리를 Koala로 받아 처리할 수 있습니다.  
> **멀티 버스 / 멀티 출력(multi-bus / multi-output)** — 여러 소리를 하나의 출력으로만 보내지 않고, 여러 출력 채널로 나누어 보내는 방식입니다. Koala의 각 패드 소리를 DAW에서 따로 처리하고 싶을 때 사용합니다.  
> **AUM** — iPhone이나 iPad에서 여러 음악 앱, 악기, 이펙트를 연결해주는 믹서/호스트 앱입니다.
{: .term-note}

> 💡 초보자 주석:
> AUv3는 “Koala를 다른 iOS 음악 앱 안에 넣어서 쓰는 기능” 정도로 이해하면 됩니다. Koala만 단독으로 쓸 때는 몰라도 괜찮지만, iPad에서 AUM이나 GarageBand와 함께 쓰려면 AUv3 개념이 중요해집니다.
{: .beginner-note}
